# PROJECT BRIEF & AGENT DEVELOPMENT GUIDELINES: PERSONAL HUB & ONLINE WEDDING INVITATION

## 1. Overview & Vision
Dự án là một hệ thống web tích hợp toàn diện:
1. **Personal Portfolio & Technical Knowledge Hub (`/` & `/blog`):** Giới thiệu bản thân (Software Developer), kinh nghiệm và chia sẻ bài viết kỹ thuật chuẩn Markdown.
2. **Online Wedding Invitation (`/wedding`):** Thiệp cưới online tương tác cao, thiết kế độc bản với tông màu Pastel tươi sáng dành riêng cho trang PUBLIC thiệp cưới, gửi thiệp cá nhân hóa theo từng khách (`/wedding/invitation/{guest_slug}`).
3. **Private Wedding Planning & Timeline (`/wedding/timeline` & `/admin`):** Phân hệ NỘI BỘ dành riêng cho chú rể & cô dâu theo dõi lộ trình 5 tháng chuẩn bị cưới, quản lý checklist công việc, cập nhật chi phí thực tế và duyệt lời chúc realtime với phong cách TỐI GIẢN (MINIMALIST), tinh tế, tinh gọn và rõ ràng.

---

## 2. Tech Stack Requirements (Latest Versions - 2026 Ready)
- **Backend Framework:** Laravel 13.x (PHP 8.4+)
- **Frontend Architecture:** Inertia.js v2 + Vue 3 (Composition API `<script setup>` with TypeScript)
- **Styling & UI Components:** Tailwind CSS v4 + Shadcn Vue / Radix Vue / Lucide Icons
- **Realtime WebSockets:** Laravel Reverb (Event Broadcasting native)
- **Admin Panel:** FilamentPHP v5
- **Content Engine:** Spatie Laravel Markdown + Shiki Syntax Highlighter + CommonMark
- **Database:** PostgreSQL 16+ / MySQL 8.0+
- **Testing & Quality Assurance:** Pest PHP v5.0, Larastan / PHPStan (Level 8+), Laravel Pint, ESLint, Prettier, Husky

## 3. UI Design System & Scope Rules

### Three-Tier Scope Architecture Standard:

1. **Trang PUBLIC Thiệp Cưới (`/wedding`, `/wedding/invitation/{guest_slug}`):**
   - **Tông Màu Pastel Tươi Sáng & Sang Trọng:** Nền Kem Ấm (`#FAF8F5`, `bg-rose-50/40`), Hồng Pastel Soft Blush (`#FDF2F8`, `#FCE7F3`), Vàng Nhạt Champagne (`#FFFBEB`).
   - **Màu Nhấn (Accent):** Hồng Đào Soft Rose (`#EC4899`, `#F43F5E`), Vàng Đồng Champagne Gold (`#D97706`), Xanh Ngọc Sage Green (`#10B981`).
   - **Màu Chữ (Typography):** Đỏ Đô Rosewood Cổ Điển (`#881337`, `text-rose-950`), Xám Than Sang Trọng (`text-slate-800`).

2. **Trang NỘI BỘ Timeline, Kế Hoạch (`/wedding/timeline`, `/admin`):**
   - **Phong cách Tối Giản (MINIMALIST Clean Design):** Thiết kế tinh gọn, mượt mà, đường nét thanh thoát, bảng màu trung tính nhã nhặn (`bg-slate-50` hoặc `bg-slate-900` tối giản), phông chữ rõ ràng, dễ nhìn.
   - **TUYỆT ĐỐI KHÔNG:** Không dùng badge màu neon sặc sỡ, thanh tiến độ đa sắc cầu kỳ hay các hiệu ứng thị giác rườm rà gây rối mắt.

3. **Trang PUBLIC Portfolio & Tech Blog (`/`, `/blog`):**
   - Theme Dark Mode hiện đại (`bg-slate-950`, `text-slate-100`, Indigo/Slate accents).

## 4. System Architecture & Routing Structure

### A. Portfolio & Technical Blog Module (`/`, `/blog`)
- `GET /` : Homepage Portfolio.
- `GET /blog` : Danh sách bài viết kỹ thuật.
- `GET /blog/{slug}` : Trang chi tiết bài viết Markdown.

### B. Online Wedding Invitation Module (`/wedding`)
- `GET /wedding` : Trang thiệp cưới tổng quan tông màu Pastel tươi sáng.
- `GET /wedding/invitation/{guest_slug}` : Dynamic Personalized Invitation.
- `POST /wedding/rsvp` : API nhận thông tin xác nhận tham dự.
- `POST /wedding/wishes` : API gửi lời chúc realtime.

### C. Private Wedding Planning & Timeline Module (`/wedding/timeline`, `/admin`)
- `GET /wedding/timeline` : Phân hệ NỘI BỘ Lộ trình 5 tháng chuẩn bị cưới (15/07 - 19/12/2026) phong cách MINIMALIST tối giản.
- **WeddingMilestoneResource:** Quản lý lộ trình 6 giai đoạn chuẩn bị cưới trong Filament Admin.
- **GuestResource:** Quản lý danh sách khách mời trong Filament Admin.
